## Checklist de qualidade
- [ ] Cada requisito possui ID único, origem, prioridade e status
- [ ] Cada RF descreve comportamento observável do sistema
- [ ] Cada RNF apresenta condição e medida de verificação
- [ ] Regras de negócio não estão confundidas com RF/RNF
- [ ] Conflitos, dependências e exceções estão explícitos
- [ ] Requisitos críticos possuem justificativa de prioridade
