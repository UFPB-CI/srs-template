# Como contribuir

1. Antes de editar, verifique se existe uma issue relacionada; crie uma se a alteração for significativa.
2. Use branch com nome descritivo (`rf-005-criterios-aceitacao`).
3. Faça commits com mensagens claras (`docs: detalha exceções de UC-001`).
4. Abra PR explicando motivo, alternativas e impacto; peça revisão de outro integrante.
5. Responda aos comentários de revisão com argumentos ou alterações. Discordâncias são permitidas, desde que justificadas.
6. Integre apenas após revisão. Para entregas, crie a tag correspondente.

**Colaboração fora do Git:** entrevistas, workshops e decisões presenciais devem ser sintetizados com respeito à privacidade, sem necessidade de transcrição integral.

**Não usar contagem de commits/linhas como indicador de mérito individual.**
